# Novera Audio

## Reproductor de música local

**Novera Audio** es un reproductor de música para Android enfocado en escuchar archivos locales de forma privada, elegante y sin depender de internet. Esta es su **primera versión pública** y seguirá mejorando poco a poco con nuevas funciones, optimizaciones y correcciones.

[**Descargar Novera Audio v1.0.0**](https://github.com/HUEVOMAN77/novera-audio/releases/download/v1.0.0/Novera-Audio-v1.0.0.apk)

## Características

| Opción | Qué hace |
| --- | --- |
| Biblioteca local | Busca y reproduce la música almacenada en el teléfono. |
| Memoria USB | Permite seleccionar archivos o carpetas completas desde una memoria USB conectada mediante OTG. |
| Formatos de audio | Reproduce MP3, M4A, AAC, FLAC, WAV, OGG, OPUS y WMA cuando el dispositivo los admite. |
| Búsqueda | Encuentra canciones por título, artista o álbum. |
| Favoritos | Guarda las canciones preferidas para acceder a ellas rápidamente. |
| Playlists | Crea listas como Viaje, Enamorados, Carretera, Noche o cualquier nombre personalizado. Puedes añadir, quitar y reordenar tu música. |
| Novera Flow | Crea una sesión local variable que prioriza tus favoritos y combina el resto de la biblioteca. |
| Playlists inteligentes | Genera listas según reglas como favoritos, canciones más largas o coincidencias de artista. |
| Cola de reproducción | Permite reproducir, pausar, avanzar, retroceder, usar aleatorio y configurar repetición de canción o cola. |
| Mini-reproductor | Mantiene la canción actual visible mientras recorres la biblioteca o utilizas otras secciones. |
| Reproductor expandido | Muestra controles grandes, progreso, seek, aleatorio, repetición y navegación entre canciones. |
| Barra de ondas | Combina el tiempo exacto de la canción con ondas animadas que reaccionan a la amplitud y energía del audio. |
| Visualizador | Muestra animaciones futuristas reactivas dentro de Novera Studio. |
| Intro animado | Presenta el ícono oficial de Novera Audio con halo pulsante, movimiento, brillo, nombre y transición hacia la aplicación. |
| Temas | Incluye Aurora, Obsidian, Nebula, Emerald y Copper. Cada tema cambia la identidad visual de la interfaz. |
| Ecualización | Permite elegir presets y modificar manualmente las bandas de frecuencia. |
| Mejoras de sonido | Incluye realce de bajos, volumen percibido y audio espacial cuando el dispositivo lo permite. |
| Reducción de ruido | Muestra y activa la función cuando la sesión y el dispositivo son compatibles. |
| Auriculares Bluetooth | Permite revisar las salidas de audio y abrir la conexión de auriculares desde Android. |
| Perfiles de audio | Guarda una configuración de sonido para una salida o unos auriculares y permite aplicarla de nuevo. |
| Marcadores | Guarda momentos concretos de una canción con nombre y posición exacta. |
| Modo A-B | Repite únicamente el fragmento comprendido entre los puntos A y B. |
| Letras LRC | Importa archivos `.lrc` locales y muestra las líneas sincronizadas con la reproducción. |
| Copias de seguridad | Exporta y restaura playlists, reglas, marcadores, letras, perfiles, favoritos y temas mediante un archivo local. |
| Widget | Muestra la canción actual y ofrece controles de reproducción desde la pantalla de inicio. |
| Notificación multimedia | Permite pausar, reproducir, avanzar y cambiar de canción desde las notificaciones y la pantalla bloqueada. |
| Asistente de voz local | Reconoce comandos como “Novera, pausa”, “Novera, siguiente”, “Novera, reproduce una canción”, “Novera, escanéame la música” y “Novera, añade esto a Carretera”. |
| Control con pantalla bloqueada | El asistente puede continuar activo fuera de la aplicación con una notificación visible, siempre que el usuario lo haya activado y el dispositivo ofrezca reconocimiento local. |
| Privacidad | La biblioteca, las playlists, los favoritos, las letras y las configuraciones se mantienen en el dispositivo. |

## Comandos de voz

El asistente se activa desde **Ajustes → Novera Studio → Asistente de voz local**. Después de conceder el permiso del micrófono, puedes usar comandos como:

```text
Novera, pausa
Novera, continúa
Novera, siguiente
Novera, anterior
Novera, reproduce Despacito
Novera, escanéame la música
Novera, crea una playlist llamada Carretera
Novera, agrega esto a playlist Carretera
Novera, repite esta canción
```

El asistente funciona con reconocimiento local cuando Android ofrece el modelo on-device. El teléfono completamente apagado no puede escuchar comandos, pero la función puede trabajar con la pantalla bloqueada mientras el servicio de escucha esté activo. Una notificación visible permite desactivar el asistente en cualquier momento.

## Primera versión

Novera Audio v1.0.0 es el comienzo del proyecto público. La aplicación continuará evolucionando gradualmente con mejoras de compatibilidad, eficiencia de batería, calidad de audio, reconocimiento de voz, organización de biblioteca, nuevas animaciones y más herramientas para escuchar música local.
